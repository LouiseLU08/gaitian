# 改天见

一个可分享房间码的多人约时间工具。发起人创建房间后，其他人在浏览器打开链接或输入房间码填写各自空闲时间，系统自动计算全员重合时段；没有重合时会按重合人数从高到低生成可协调备选。

## 运行

```bash
python server.py
```

启动后访问 http://127.0.0.1:8765 。房间数据保存在 `data/rooms.json`。

如需换端口：

```powershell
$env:PORT = "9000"
python server.py
```

## 主要流程

1. 发起人填写主题、人数、自己的昵称，设置 DDL 日期与时间，再通过日历选择自己的空闲时间。
2. 其他人通过房间码或房间链接加入，在同样的日历里按 30 分钟粒度选择空闲时间。
3. 全员填写后自动列出重合时段；选择其中一个即完成。
4. 时间确定后生成包含主题、人数和时间的备忘文案，可复制，也可再约一次。
5. 若没有全员重合，系统会展示当前最多人可到的备选时段，并请缺席者确认能否调整；被排除后自动进入下一备选。
6. 备选全部排除后，发起人可重新开始一轮并调整 DDL。

如需把链接设为固定的公开地址，可先配置公开域名再启动：

```powershell
$env:PUBLIC_BASE_URL = "https://example.com"
python server.py
```
